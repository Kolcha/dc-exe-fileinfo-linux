## Why this?

This plugin is something I looked for many years, but had not time to dig in
into the topic (as my knowledge there are basic), do some some research, and
finally implement it.

For ~20 years (since ~2009 when I used Total Commander, and then switched to
Double Commander in ~2012) I used famous [FileInfo (now open source!)][FileInfo]
plugin, that became invaluable tool for me in Windows environment. This plugin
is supposed to fill this gap in Linux world where I live most of time nowadays.

It helps me a lot with analysis of proprietary / vendor binaries from Android.

Hope some people will find it useful too for their cases.

## What it is and what is not

This plugin is very basic binary file info viewer, mostly as analog to FileInfo
plugin mentioned earlier. It is not supposed to be some PRO / complex tool for
binary file analysis. Its primary task is dependencies analysis.
